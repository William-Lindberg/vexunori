What this means for security review

  • No external audit. Vexunori has not had an independent security audit.
  • The source code is not public, so independent review of Vexunori's own code is not currently possible. You cannot check for yourself that the app does what these pages describe; you have to trust the maintainer's description, which we try to keep exact, including the feature status and the known limits.
  • No custom cryptography. Encryption, signatures and key handling come from the widely used open-source libraries listed below (nostr-tools, @noble/*) and from the browser's built-in WebCrypto. Those libraries can be reviewed on their own; how Vexunori uses them cannot be independently checked today.
  • What you can check: that the APK you downloaded matches the published SHA-256 checksum and signing certificate (see Download). That proves the file was not changed on the way to you. It says nothing about what the code does.

Open-source licences

Vexunori includes the third-party open-source libraries below. Each is covered by its own licence, which applies only to that library and gives no rights to Vexunori itself. No analytics, advertising, crash-reporting or AI libraries are included.
