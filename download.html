Download for Android

Vexunori is experimental. It is new, has had no independent security audit, and the Android app has not yet been tested on many real phones — you will probably find bugs. Please report them on GitHub with what you did, what happened, your phone or browser and the Vexunori version (Settings → About). Never include your secret key, passphrase or private messages. Don't rely on Vexunori alone where your safety depends on it.

Vexunori for Android is an APK you install directly from this website. It is not on Google Play or any other app store. On a computer, iPhone or iPad you can use the web app instead.

Checking for a published build…

Install the APK

  1. Download the APK on your phone (or copy it to the phone).
  2. Check the SHA-256 checksum (see below) before you install. It takes a minute and protects you from a damaged or swapped file.
  3. Open the downloaded file. Android will say that your browser or file manager is not allowed to install unknown apps.
  4. Tap Settings and turn on Allow from this source (Settings → Apps → Special app access → Install unknown apps → your browser). The exact wording differs between phone makers.
  5. Go back and tap Install. Google Play Protect may warn that it does not know the app; that is expected for an app that is not in the Play Store. Read the warning and decide.
  6. Turn Install unknown apps off again for that browser afterwards.

The app needs Android 7.0 or newer with an up-to-date Android System WebView. It asks for permissions only when you use a feature that needs one (camera for QR codes, microphone for calls or Morse listening, notifications).

Verify the checksum

The SHA-256 checksum shown above is computed from the exact file on this server. Compare it with the output of one of these commands. Every character must match.

macOS

shasum -a 256 vexunori-VERSION.apk

Linux

sha256sum vexunori-VERSION.apk

Windows (PowerShell)

Get-FileHash .\vexunori-VERSION.apk -Algorithm SHA256

Android

Some file managers show checksums in the file's details. Otherwise, verify on a computer before copying the file to your phone.

A matching checksum proves the file was not changed between this server and you. It does not prove that this server or the build machine was not compromised. Comparing against the same checksum published in a second place (for example the release page where the APK is also published) gives stronger assurance.

Check the signing certificate

Android refuses to update an app with an APK signed by a different key, so the signing certificate is what links every future update to this one. With the Android SDK build tools installed:

apksigner verify --print-certs vexunori-VERSION.apk

The line Signer #1 certificate SHA-256 digest should show: (shown above once a build is published)

If a later APK has a different certificate, Android will refuse to install it over the existing app. Do not uninstall and reinstall to get around that unless you know why the key changed — uninstalling also deletes your local data.

Updates

  • The app does not update itself and does not check for updates in the background. Come back to this page to see whether a newer version is published.
  • Install a new APK over the old one: your data stays. Make an encrypted backup first anyway.
  • Release notes are shown above for the current build.

Copies from other places

Install Vexunori only from this page. The licence does not allow anyone else to redistribute the APK, and the source code is not public, so there are no community builds. An APK offered anywhere else is not from this project and may have been modified. If its signing certificate does not match the one shown above, do not install it.

Testing status

This version has been built and checked by automated tests only. It has not yet been run on a physical phone or an emulator. Installing, the Android Keystore, notifications, the camera and microphone prompts, the built-in Tor, the Private Browser, Tor via Orbot and screenshot protection are untested on real hardware. Please make an encrypted backup and do not rely on it for anything important yet.
