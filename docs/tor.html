Tor

Tor hides your IP address from the relays you connect to. It does not hide your public key, and it does not protect against timing analysis or a compromised device.

Android with Orbot Experimental

  1. Install Orbot (from F-Droid or Google Play) and start it.
  2. In Vexunori, Settings → Tor, choose Prefer Tor or Tor only (strict). The proxy address defaults to Orbot's HTTP proxy, 127.0.0.1:8118.
  3. Vexunori tells Android System WebView to send all of the app's web traffic — relay connections and checks — through that proxy, and then runs a Tor check.

The status says Tor confirmed only after the check sees your traffic leaving from a Tor exit. Until then it says "Checking", "Not using Tor" or "Check failed" — never a decorative onion icon.

This needs an Android System WebView that supports proxy override; the Tor settings tell you if yours does not. Tor mode has not yet been tested on a phone with Orbot.

Prefer vs strict

Prefer Tor
Uses Orbot when possible. If Tor is not confirmed, Vexunori still connects directly and shows "Tor not confirmed".
Tor only (strict)
No relay connections at all until a check confirms Tor. If Orbot stops, connections are closed and messages wait in the queue. Calls are disabled, because their audio/video cannot go through Tor.

What goes through Tor

  • Through Tor (when confirmed): relay connections, the Tor check.
  • Not through Tor: links you open — they open in your normal browser; calls (disabled in strict mode); parcel files shared via other apps.

The Tor check contacts check.torproject.org, and as a fallback api.ipify.org (to learn the public address) and onionoo.torproject.org (to look it up in the Tor relay list). Checks run only while Tor mode is on or when you press "Check now".

The Vexunori app is not the Tor Browser, and the WebView inside it does not have Tor Browser's anti-fingerprinting protections.

Web browsers

A web page cannot send its own traffic through Tor. In a normal browser, Tor mode is unsupported. If you open the web app in Tor Browser, Vexunori can detect that and shows "Tor confirmed (this browser)"; strict mode then works too.

Troubleshooting

  • "Not using Tor": check that Orbot is running and connected, and that its HTTP proxy port matches the setting.
  • "Check failed": the check services may be blocked or slow over Tor; press "Check now" again.
  • Some relays block Tor exits. Add relays that accept Tor if messages stay queued.
