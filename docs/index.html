Documentation

These guides explain how to use Vexunori and, just as important, what each feature does not do. If something here disagrees with what the app shows, the app is right and this page is out of date — please tell us.

New here? Start with Getting started. Wondering whether Vexunori fits your situation? Read the threat model first.

More information

Vexunori is free to use but not open source, so its source code and technical documents are not published. The public information is on this website: these guides, the feature status with every known limit, and the security summary.

Vexunori — Private by design. Connected by choice.
