Groups

Groups are private: each group message is end-to-end encrypted separately for every member and carries the group's id, so there is no group server and no group key stored on a relay.

Creating a group

Choose Groups → New group, give it a name and pick members from your contacts. You become the first admin. Every member's app receives the member list and each member's inbox relays so they can reach each other.

Size limits

  • Up to 100 members. We recommend 50 or fewer.
  • Because every message is encrypted and uploaded once per member, a message to 50 people means 50 uploads. Large groups are slower, use more data and battery, and hit relay rate limits sooner — especially with attachments.

Invite links and QR codes

  • Admins can create an invite link in the group's Info tab, with an expiry (1 hour to 30 days, or never) and a limit on how many people can join with it. Each link is also shown as a QR code.
  • The link contains the group id and name, a random secret, and the inviting admin's public key and relays. It never contains the member list. The secret is in the part of the link after #, which browsers do not send to the web server.
  • Someone who opens the link (or scans the code in Contacts → Add contact → Scan group QR) sees a preview and taps Join. Their app sends an encrypted join request with the secret, their public key, display name and relays to the admin.
  • The admin's app checks the secret, expiry, number of uses and whether the link was revoked, then adds the person like any other new member. This only happens while the admin's app is running, so the joiner sees “Waiting for an admin's app to approve; this happens the next time an admin is online.”
  • Only the device that created the link can approve it. If the link is invalid, nothing is sent back: the joiner keeps waiting and should ask for a new link.
  • Anyone who gets hold of a valid link can join. Use short expiries and limits, and revoke links you no longer need.

Admins

  • Admins can rename the group, add members and remove members. Other members cannot.
  • Every change is numbered; apps ignore changes from non-admins and older changes, so a removed admin cannot undo things later.
  • Anyone can leave. If the last admin leaves, every app promotes the same next member to admin.
  • Admin rights are enforced by each member's app. A member running a modified app can ignore them on their own device, but cannot force other apps to accept their changes.

What members can see

  • All members see the member list (public keys and names) and every message sent while they are a member.
  • New members do not receive earlier chat messages. They do receive the group's shared workspace (tasks, notes, polls…).
  • Removed members stop receiving new messages because senders stop encrypting for them. They keep everything they already received.
  • Relays see one envelope per member, addressed to that member, so a relay serving many members can guess the group's size and activity.
