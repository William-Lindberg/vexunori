# Vexunori

**Private by design. Connected by choice.**

Vexunori is a privacy-focused messenger and collaboration app: end-to-end encrypted chats and groups, a Morse workspace, an encrypted Vault, Spaces, shared group workspaces and a Privacy Center.

- **Website & web app:** https://william-lindberg.github.io/vexunori/ (open the app at https://william-lindberg.github.io/vexunori/app/)
- **Android app:** download the APK from the [Releases](https://github.com/William-Lindberg/vexunori/releases) page or the website's Download page. It is not on Google Play. Check the SHA-256 checksum shown there before installing.

This repository only hosts the published website and the Android app. Vexunori is **free to use but not open source**: the source code is not published. See [LICENSE](LICENSE). The open-source libraries Vexunori uses are listed on the website's Licence page.

Status: version 0.1.0. The Android app has been build-verified but not yet tested on physical devices. See the website's Features and Security pages for what works, what is experimental, and the known limitations.
